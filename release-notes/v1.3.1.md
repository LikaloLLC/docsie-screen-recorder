# Docsie Screen Recorder v1.3.1

## Template catalog

- Added the Docsie generation template picker to the desktop Video to Docs flow.
- Synced the desktop picker with the Docsie template catalog categories and template IDs, so jobs can submit a selected `generation_template_id`.
- Added dark-theme picker styling to match the recorder settings modal.
- Added template preview rendering for markdown headings, lists, code blocks, and tables.
- Added support for richer `preview_markdown` payloads from the Docsie API, with fallback to existing `example_markdown` on older API deployments.
- Fixed escaped Unicode template icons such as `\uD83D\uDD0D` rendering as raw text instead of emoji.

## Deployment note

For the full preview experience, deploy the matching Docsie API update that exposes `preview_markdown` and decoded template icons from `/video-to-docs/templates/`. Older API deployments will still list templates, but previews fall back to the shorter sample markdown.
