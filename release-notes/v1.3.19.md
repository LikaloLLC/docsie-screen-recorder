## Docsie Capture Companion 1.3.19

This release improves the Japanese MREAL-to-documentation evaluation workflow:

- Japanese localization across Capture Companion and Docsie publishing screens
- documentation language now follows the selected app language by default
- an explicitly selected documentation language remains unchanged
- stable latest-release aliases for Windows and Linux downloads

Capture Companion can record a selected Windows application and expert narration, then
send the recording to Docsie to generate structured SOPs, manuals, PDFs, FAQs, and
knowledge-base content.
